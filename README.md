# 🛍️ Abayas-Vente

**Abayas-Vente** est une application web dédiée à la présentation et à la vente d'abayas.
Elle offre une interface moderne et intuitive permettant aux utilisateurs de découvrir les différents modèles disponibles et de consulter leurs informations.

## 🌐 Application en ligne

🚀 **Accéder à l'application :**
👉 https://abayas-vente.vercel.app/

## ✨ Fonctionnalités

* 🛍️ Consultation des produits
* 👗 Présentation des différents modèles d'abayas
* 🔎 Recherche et navigation entre les produits
* 📱 Interface responsive adaptée aux différents écrans
* 🎨 Interface moderne et intuitive
* ⚡ Navigation rapide et fluide

## 🛠️ Technologies utilisées

* **JavaScript**
* **React**
* **HTML5**
* **CSS3**
* **Vite**
* **Vercel** — Déploiement de l'application

L'application sera ensuite accessible à l'adresse indiquée par Vite dans le terminal.

## 🌍 Déploiement

L'application est actuellement déployée avec **Vercel**.

👉 **[Voir l'application en ligne](https://abayas-vente.vercel.app/)**
